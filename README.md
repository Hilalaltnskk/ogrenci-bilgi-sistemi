# Öğrenci Bilgi Sistemi
C# ve MySQL kullanılarak geliştirilen öğrenci bilgi sistemi uygulamasıdır.
## Proje Hakkında
Bu proje, öğrencilerin ve öğrenci bilgilerinin yönetilmesi amacıyla geliştirilmiştir.
Uygulama üzerinden öğrenci bilgilerinin eklenmesi, görüntülenmesi, güncellenmesi ve silinmesi gibi işlemler gerçekleştirilebilir.
## Kullanılan Teknolojiler
- C#
- MySQL
- Windows Forms
- .NET
## Projenin Amacı
Öğrenci bilgilerinin bilgisayar ortamında düzenli ve kolay bir şekilde yönetilmesini sağlayan bir masaüstü uygulaması geliştirmektir.
## Geliştirme
Proje geliştirilmeye ve yeni özellikler eklenmeye açıktır.
